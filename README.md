# MAA-HazeWorld

**《苍雾世界》日常自动化脚本**，基于 MaaFramework 的图像识别 + 模拟点击实现。

## 功能

| 任务 | 说明 | 设置项 |
|---|---|---|
| **游戏初始化** | 拉起游戏、过启动页 / 公告 / 更新，回到可操作界面 | — |
| **每日日常准备** | 签到 → 好友点赞 → 邮箱 → 商城每日礼包 → 每周演习商店兑换 | 好友点赞 / 邮箱领取 / 商城每日礼包 / 每周演习卷 |
| **每日演习** | 打演习、代理作战 | 补充演习卷 |
| **指挥室** | 远征派遣、收取 | — |
| **主线扫荡** | 异兽清剿 / 核心制造 / 队员特训 / 装甲进阶，四选一 | 选择扫荡关卡 / 选择关卡难度 |
| **活动扫荡** | 扫荡当期活动，活动结束后自动跳过 | 活动抽卡 |
| **通行证** | 领取通行证任务奖励 | — |
| **每日任务** | 每日 / 每周 / 每月三栏，共 6 档奖励 | 各栏、各档独立开关 |
| **每月兑换商店（测试版）** | 荣誉凭证（每周）+ 兑换商店（每月） | 兑换商店 / 荣誉凭证 / 各物品开关 |
| **关闭游戏** | 关闭游戏进程 | — |

## 说明

- **每日日常准备**：各段独立开关，勾哪个跑哪个；签到段固定执行。段内识别不到会自动跳过并标记完成，下一段继续。
- **每日演习**：北京时间 2:00~6:00 自动跳过（维护时段）；演习券不足时按需补充。
- **活动扫荡**：活动时间到期自动跳过，不需要手动关；扫荡完想抽卡，把「活动抽卡」打开即可。
- **每月兑换商店（测试版）**：荣誉凭证按周、兑换商店按月记录，本周期兑换过会自动跳过并打日志；商店里识别不到物品会自动滑页（最多 5 次），仍找不到则输出日志并返回主界面。
- 所有开关都在任务右侧的齿轮里。

> 可领取的奖励档位按点数解锁，点数不够时界面上不会出现，属正常现象。长期达不到的档位建议直接在设置里关掉，能少等一轮超时。

## 环境要求

- Windows 10 / 11 x64
- 支持 ADB 的安卓模拟器（MuMu、雷电、逍遥等），推荐 1280×720 横屏
- 《苍雾世界》，包名 `com.feimo.hazeworld.main`

## 安装与使用

1. 到 [Releases](https://github.com/sleeeeeorz/MAA-HazeWorld/releases/latest) 下载 `MAA-HazeWorld-win-x86_64-*.zip`
2. 解压到任意目录（路径别带中文和空格，避免识别异常）
3. 启动模拟器，确认游戏能正常进入
4. 运行解压目录里的主程序，在「设置 → 连接设置」填模拟器 ADB 配置
   - **ADB 路径**：选模拟器安装目录下的 `adb.exe`（如 `E:\MuMu\MuMuPlayer\nx_main\adb.exe`），不要选模拟器主程序 `MuMuNxMain.exe`，否则会提示连接模拟器失败
   - **ADB 地址**：写完整 `IP:端口`（MuMu 常见 `127.0.0.1:16384`，雷电 `5555`），只填端口号会连不上
5. 刷新截图确认能看到游戏画面，左侧勾选任务，然后开始

> 装完包里自带「日常」「活动」两套配置：日常跑主线扫荡，活动跑活动扫荡，其他任务相同，可直接切换。
